# After the PR is open

Board moves happen through the project's built-in workflows (linked PR moves the issue to In progress, merged moves
it to Done). The one manual move: when the first story of an epic starts, move the epic to In progress.

Never merge; the user merges. Cap the feedback loop at five rounds in total, then stop and summarise what is left.
Report the PR URL, what was built, checks and review status, what was declined or left for the user, and follow-up
issues worth creating. Ask before creating follow-ups.
